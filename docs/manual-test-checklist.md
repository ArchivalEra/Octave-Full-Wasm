# 真机手测清单（工单 12 的第一交付物 · 可复跑结算件）

> **为什么有这份**：桌面矩阵绿 ≠ 手机上能用。触屏、虚拟键盘、`ginput`/`pause` 的实际手感、
> 渲染性能，从没在真机上过一遍。本清单是**入库的可复跑结算件**——下一台设备到手，
> 照着逐项跑并把"实际"列回填，**每项都写明什么算红**。"我试了一下能用"不算数。
>
> **对象**：现役双档站点（如 `http://<主机>:8761/`，带头服务）+ `matrix-android.html`。
> **范围说明**：图形只有 **gl4es→WebGL2/GPU** 一条（OSMesa 已于 2026-09-23 退役，
> `link-web.sh:314` 对它硬 FATAL）⇒ 本清单不含 OSMesa 列；若日后复活 OSMesa
> （配方在 git 历史 `graphics-osmesa` 分支），另开工单再补列。
>
> **纪律**：发现红项 ⇒ **各自开成新工单**（`.scratch/open-questions/issues/`，带 `Settling:`），
> 别塞回工单 12。全部绿 ⇒ 回填工单 12 并附本文件的实际列。
