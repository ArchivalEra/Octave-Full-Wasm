## Solution

分三步，每步独立可验：

1. **机制层整层换到 `6e4e6e8`**（`zreflect/` 21 个共改文件 + `reflect-hooks/`），
   **保留本仓两个专属文件**（`mail-read.py`、`measure_octave.py` 上游没有）。
2. **给上游补一条形状**（端口号）——**报回上游**，不是只在本仓魔改：
   本仓 `8761`/`8768`/`8868` 是**固定部署矩阵**（doctor.json 的活性目标），不是测量值。
   本地先落一份（带确切端口枚举，**不许放宽成 `\d{4}`**），同时把补丁投给 Einfacht。
3. **把 74 处真手抄的数字按 #24 的两种合法出处置理**：
   - 能复跑的 ⇒ 进 `build/FACTS.json`（带 `cmd`），正文改 `[[键名]]`
   - 不能复跑的（如"某次 grep -c 的结果"）⇒ 包进行内代码（纪律明说示例数字本就该豁免）

## Implementation Decisions

- **整层替换，不摘件**（上游 `mail/039` 已裁定过这条：摘件 = 两处会漂移的拷贝）。
  `zreflect/` 下上游有的 `.py` 全量覆盖；本仓专属 `mail-read.py` / `measure_octave.py` **不动**。
- **`reflect-hooks/`** 同步（`Einfacht.env` 的旋钮仍是本仓口径，**不覆盖**；
  `einfacht-env.sh` / `pre-commit` / `pre-push` 按上游换）。
- **端口形状**：加一条 `_SHAPE_PATTERNS`，值是**本仓真实端口的枚举**（不是 `\d{4}`）。
  理由写进注释：放宽成任何 4 位数会把 `1246`/`1650` 这类测量值一起放行 = 关掉判据。
  **同时**给 Einfacht 提一个 issue/信，附本仓实测（47 条同类）。
- **74 处手抄数字的处理批**：按"能复跑 ⇒ 进台账 / 不能 ⇒ 包代码"分流。
  **不许**用 `--allow-drop` 或整段 `[[键名]]` 糊过去（那是 #24 要拦的形状）。
- **`REFLECT_PHASES`（上游 #21 新增旋钮）**：本仓目前没有自定义相位，**不启用**，
  但要在 `Einfacht.env` 里留一条注释说明"看见了、不需要"。
- **回滚点**：升级前打一个 tag 或记下 sha，`git revert <升级提交>` 必须能干净回旧版。
